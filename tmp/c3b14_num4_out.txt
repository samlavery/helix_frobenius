U4 -- BERNSTEIN / STIELTJES / complete monotonicity in |v|
==============================================================================
  A completely monotone function of |v| is a mixture int exp(-lam|v|) dmu, which has
  one-sided derivative -int lam dmu < 0 at 0 unless mu = 0.  R is even and smooth, so
  R'(0+) = 0.  Hence R is NOT completely monotone in |v|, and every Bernstein /
  Stieltjes representation in |v| is structurally unavailable -- the SAME obstruction
  that kills Polya.  This is a proof, not a measurement.
  consistency check: (R(h)-R(0))/h at h=0.001 is -7.385376e-04 -> 0 as h->0
                     (R(2h)-R(0))/(2h) = -1.477024e-03

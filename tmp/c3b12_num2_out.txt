  EXACT ARGUMENT (pencil, not numerics).  With c = cosh x >= 1 and a = 1/e,
    h(c) := (log g)'' = a(2c + a)/(2 + ac)^2,
    h'(c) = 2a(2 - ac - a^2)/(2 + ac)^3, so h is maximised at c* = (2 - a^2)/a,
    where ac* = 2 - a^2, 2 + ac* = 4 - a^2, 2c* + a = (4 - a^2)/a, hence
    max h = 1/(4 - a^2) = 0.258754658758, and 1/(4-a^2) < 1/2 iff a^2 < 2.
    Since a = 1/e < 1 this holds, so L1_c = Xi_c^2 (1/2 - h) > 0 for EVERY real x.
    CHECK against the scan above: 1/2 - 1/(4-a^2) = 0.2412453412
    (An earlier draft of this file said the max was at c = 1, value a/(2+a).
     That was wrong; h increases to c* first.  The conclusion is unchanged.)

  CONSEQUENCE, and it is the batch's most useful negative-turned-positive:
  Phi_c REFUTES the full four-moment leaf (batch 11 F1) but SATISFIES the u^2
  sub-leaf.  The sub-leaf is therefore STRICTLY WEAKER, and the batch-11
  counterexample does NOT obstruct an unconditional proof of it.

  Xi_g > 0 everywhere (a positive mixture of two Gaussians), so Phi_g has no real
  zeros -- yet it VIOLATES the u^2 sub-leaf.  So the two counterexample kernels
  SEPARATE the two statements:
     Phi_c : violates the FULL leaf,  satisfies the u^2 sub-leaf
     Phi_g : violates the FULL leaf,  violates  the u^2 sub-leaf
  Consequences, both load-bearing: (1) the sub-leaf is STRICTLY WEAKER than the
  full leaf, so batch 11's Phi_c counterexample does NOT obstruct proving it;
  (2) the sub-leaf is nevertheless NOT implied by evenness + positivity alone,
  since Phi_g is even and positive and fails it.  Any proof of the sub-leaf must
  use a property of Phi_Xi beyond positivity.

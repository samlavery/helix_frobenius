D1 -- THETA-MODE: termwise log-concavity does NOT transfer to the sum
==============================================================================
  The repository compiles riemannXiKernelTerm_log_strictConcaveOn (each summand is
  strictly log-concave on Ici 0).  Does that give log Phi concave?  NO -- a sum of
  log-concave functions need not be log-concave.  Explicit witness:
    g(x) = exp(-x^2) + exp(-100(x-3)^2): both summands log-concave,
    max (log g)'' = 8.229368e+02 > 0  ->  g is NOT log-concave
  So the compiled per-term result CANNOT be used to discharge the Phi hypothesis,
  and this batch does not use it that way.  Recorded as a FAILED transfer.

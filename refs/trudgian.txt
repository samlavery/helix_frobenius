                                                  Abstract. This paper concerns the function S(T ), the argument of the Rie-
                                                  mann zeta-function along the critical line. The main result is that
                                                                  |S(T )| ≤ 0.111 log T + 0.275 log log T + 2.450,
                                                  which holds for all T ≥ e.
